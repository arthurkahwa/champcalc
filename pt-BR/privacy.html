Política de Privacidade

Última atualização: 9 de agosto de 2026

English · Deutsch · Español · Français · 日本語 · Português · Русский · 简体中文 · العربية

O Champ Calc não coleta, armazena ou transmite nenhum dado pessoal. Não há conta, não há cadastro, e nenhum dado do usuário é enviado para fora do seu dispositivo.

O que o app faz

O Champ Calc lê a classificação e o calendário da Fórmula 1, disponíveis publicamente, a partir de um arquivo JSON estático hospedado no GitHub (raw.githubusercontent.com/arthurkahwa/champcalc) e calcula as chances de título a partir daí, inteiramente no seu dispositivo. Essas requisições não carregam identificadores de conta, de dispositivo, nem qualquer conteúdo do usuário — são o mesmo tipo de requisição que qualquer pessoa faria ao abrir uma página pública na web.

O que permanece no seu dispositivo

  • Preferências (por exemplo, se a introdução foi concluída, seu piloto/equipe selecionado) — armazenadas localmente via UserDefaults, o sistema padrão do iOS, nunca transmitidas.
  • Um cache local do JSON de dados da temporada, armazenado no diretório Caches do app, para que ele continue funcionando offline ou se a fonte de dados ficar indisponível por um curto período. Também nunca transmitido.

Nenhum dos dois jamais sai do seu dispositivo. Excluir o app também exclui esses dados.

Notificações push

Se você aceitar quando solicitado, o Champ Calc envia no máximo uma notificação push por corrida concluída (por exemplo, a conquista de um título ou uma eliminação matemática). Isso exige que seu dispositivo registre um token de dispositivo do APNs, enviado apenas para a função de entrega de notificações do próprio app — nunca para serviços de análise, publicidade ou de terceiros — unicamente para endereçar essa notificação ao seu dispositivo. Se você recusar a permissão, isso fica totalmente desativado; todos os demais recursos do app continuam funcionando normalmente.

O que não fazemos

  • Nenhum SDK de análise, telemetria ou relatório de falhas.
  • Nenhuma publicidade ou SDK de anúncios.
  • Nenhum SDK de terceiros de qualquer tipo.
  • Nenhuma conta, login ou conteúdo gerado pelo usuário.
  • Nenhum rastreamento, e nada é compartilhado ou vendido a ninguém.

Privacidade infantil

O Champ Calc não coleta intencionalmente dados de ninguém, incluindo crianças, porque não coleta dados de forma alguma. O único dado que o app pode enviar para fora do dispositivo — um token de dispositivo para notificações push, e apenas com seu consentimento explícito — não está vinculado a nenhuma identidade e é usado exclusivamente para entregar a notificação descrita acima.

Alterações nesta política

Se as práticas de dados do Champ Calc mudarem, esta página será atualizada primeiro, e a mudança será refletida nas declarações de privacidade do app no App Store Connect.
